# Wildhaven — Cervalume + Lobrapedra modeling v01

First real GLBs for the two species that previously existed only as dossiers.

Art direction intentionally restrained after concept review:
- Cervalume: plausible cervid/ungulate anatomy, compact natural antlers, subtle pale coat dappling instead of magical glow.
- Lobrapedra: robust canid-like predator for rocky forest edges, with only a few low-profile keratinized/callused dorsal plates; no stone armor shell or fantasy spikes.

Both receive skeletal rigs, behavior clips, LOD0/1/2 and real static renders. WebGL animated preview is generated only after final GLBs are published.
