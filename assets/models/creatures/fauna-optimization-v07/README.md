# Wildhaven — Fauna Optimization v07

Lote de duas espécies: Silvarano (variantes temperada e tropical) + Folhisco.

Ambas são criaturas com skinning e já possuem baixa contagem estrutural de draw calls. Por isso o pipeline preserva a estrutura de mesh/node/skin e simplifica as primitivas individualmente.

A prévia animada deste lote usa Three.js/WebGL + Playwright para executar os rigs e clipes reais dos GLBs otimizados. O GIF principal mostra Silvarano sprint e Folhisco jump_flap lado a lado.
