# Wildhaven — Cervalume + Lobrapedra Guide v02

Revisão completa dos dois modelos conforme o Guia Visual Oficial das Criaturas 3D v1.0.

Mudanças estruturais:
- modelos v01 preservados;
- novos v02 em subpastas próprias;
- silhueta reconstruída com lofts/prismas facetados e planos definidos;
- corpo não é composto por bolas/cápsulas visivelmente coladas;
- face normals/arestas duras no GLB exportado;
- cabeça/focinho, joelhos/jarretes, patas/cascos e caudas possuem construção própria;
- Lobrapedra troca placas soltas por uma baixa faixa/calosidade dorsal integrada;
- animações deixam de usar um gait genérico compartilhado e passam a ter curvas específicas para cervídeo e canídeo;
- LOD0/LOD1/LOD2 e previews reais obrigatórios;
- status permanece revisão artística até aprovação do usuário.
