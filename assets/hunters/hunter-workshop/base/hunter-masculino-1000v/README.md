O GLB original enviado pelo responsável possui **959 vértices exportados**, **1.000 triângulos**, **19 ossos**, uma malha e animações `Walking` e `Running`.

Consulte `manifest.json` para hashes e nomes reais dos ossos. A meta de 1.000 triângulos vale para o **corpo base** e não para todo o Hunter equipado.
