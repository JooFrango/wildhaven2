# Rig compartilhado

Consultar o manifesto do Hunter base. Nomes iguais não garantem compatibilidade: conferir hierarquia, bind poses, rest pose e escala. Um controlador de animação e um esqueleto por Hunter. Peças deformáveis remapeiam seus joints; acessórios rígidos podem acompanhar `Head`, `LeftHand` ou `RightHand`. Testar deformações nas articulações.
