# Folhisco — conceitos de arte

## Direção visual aprovada para estudo (ainda não arte final)

- Referência anatômica: galinha selvagem / ave de solo florestal.

- Paleta: cobre/ferrugem, marrom, creme e poucos contrastes escuros.
- Olhos laterais âmbar e bico resistente, sem aparência cartunesca excessiva.
